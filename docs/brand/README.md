# Logo se-vezmou.cz (návrh, kolo 2)

Zbývají dvě varianty: **A (prsteny)** a **C (adresa)**. Po výběru ostatní soubory smazat.

| Soubor                 | Použití                                      |
| ---------------------- | -------------------------------------------- |
| `logo-<v>-*.svg`       | plné logo (symbol + název), světlé pozadí    |
| `logo-<v>-*-tmave.svg` | totéž na tmavém podkladu (`#1b2a23`)         |
| `logo-<v>-*-mono.svg`  | jedna barva (tisk, razítko, fax)             |
| `symbol-<v>.svg`       | samotný symbol (avatar, sociální sítě, tisk) |
| `favicon-<v>.svg`      | zjednodušený symbol pro 16 až 48 px          |

Pravidla (podle rešerše, viz níže):

- Minimální šířka: plné logo 80 px, symbol 24 px, favicon 16 px (6 mm v tisku).
- Ochranná zóna kolem loga: čtvrtina jeho šířky.
- Barvy: borovice `#365c4e`, skořice `#8e503c`, inkoust `#1b2a23`, pergamen `#f7f4ed`. Na tmavém podkladu světlejší odstíny ze souborů `*-tmave.svg`.
- Nenatahovat, nepřebarvovat, nedávat efekty ani stíny, nepoužívat na rušivém pozadí.
- Text je převedený na křivky (DM Sans Bold), soubory nepotřebují fonty.

Zdroje: We and the Color (Logo Design Trends 2026), LogoLounge 2026 Logo Trend Report, brainy.ink (Responsive Logo Systems), logo87 (Favicon Best Practices).
